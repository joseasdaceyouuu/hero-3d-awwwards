# Hero 3D Awwwards — Skill + Agent Loop + Memory System

> Awwwards-level hero section design skill with autonomous Agent Loop system
> (Creator → Auditor → User Simulator → Corrector) + memory system that learns
> across sessions. Built with Next.js, React Three Fiber, GSAP, and GLM-5.2.

## What this project contains

### 1. The Skill (`skills/hero-3d-awwwards/`)
A reusable skill that teaches AI agents to design Awwwards Site of the Day-level
hero sections with 2.5D and 3D animation. Covers:

- **5 archetypes**: 2.5D Parallax, 3D Scene with GLB, Shaders GLSL, Distortion hover, Cinematic 3D Text
- **3 stacks**: React Three Fiber + GSAP, Three.js vanilla, CSS 3D + GSAP
- **Reusable assets**: GLSL shaders (noise, distortion, fluid, postprocessing), React components, setup scripts
- **Web 2026 standards**: Clarity-First, WebGPU/TSL, Draco+KTX2, accessibility, performance budgets

### 2. Agent Loop System (`scripts/hero-loop.py`)
Autonomous 4-agent loop that iterates until quality is reached:

```
Creator → Auditor → User Simulator → Corrector → (repeat)
```

- **Creator**: generates hero code following the skill
- **Auditor**: evaluates 26 objective criteria (performance, accessibility, code quality)
- **User Simulator**: evaluates subjective quality (wow factor, soul, SOTD-worthiness)
- **Corrector**: applies minimal fixes based on both evaluations

### 3. Memory System (`scripts/memory/`)
5-tier cognitive memory that learns across sessions:

| Store | Purpose |
|---|---|
| Working Memory | Current iteration state |
| Episodic Memory | Raw past hero sessions |
| Semantic Memory | Extracted atomic patterns |
| Procedural Memory | Reusable skills (Voyager-style) |
| Negative Knowledge | Anti-patterns to avoid |

Features:
- Tri-score retrieval (semantic + recency + importance)
- TOON compression for JSON (30-60% token savings)
- Graduated reduction by iteration age
- Pattern extraction with LLM (GLM-5.2)
- Cross-session learning

## Quick Start

```bash
# Install dependencies
bun install

# Run the dev server
bun run dev

# Open http://localhost:3000
# Click "Memory" button (top-right) to see the memory dashboard
```

## Using the Agent Loop

```bash
cd skills/hero-3d-awwwards/scripts

# Run the full agent loop with memory
python3 hero-loop.py \
  --prompt "Design a hero with aurora borealis for a creative agency" \
  --llm zai-direct \
  --model glm-5.2 \
  --vertical agency \
  --archetype Shaders \
  --stack r3f

# Run consolidation (promote patterns to skills)
python3 -m memory.consolidation --db memory.db --lancedb .lancedb

# Query memory for patterns
echo '{"brief":"atmospheric fog cinematic"}' | python3 retrieve.py
```
